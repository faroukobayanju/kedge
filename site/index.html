How the catch works

  1. 1

    Plan

    Kedge reads the failing tests and the base branch, and writes down which files a fix may touch and how many tests must survive.

  2. 2

    Check every step

    After each agent step it re-runs the tests, diffs the files and compares the count against the base branch. No model judges the agent; the tests do.

  3. 3

    Strike and rewind

    A deleted test, an off-plan edit, a repeat attempt or a false “fixed” is struck. Kedge resets to the last good commit and hands the agent a note on what it did wrong.

  4. 4

    Keep

    Only a green result that holds on a second run becomes a draft PR, with every step traced and every agent commit checkpointed.
