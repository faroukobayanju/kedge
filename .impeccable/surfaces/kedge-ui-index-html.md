# Surface: Kedge replay theater (`kedge ui`)

Mode: Experience. The run is the show; seen mostly in a 2-minute demo video by hackathon judges (Entire, neatlogs, Orchestrator). Memorable moment: the rewind.
Data: runs/*/steps.jsonl, plan.json, meta.json (base_total), result.json via /api/runs.
States: green, shipped short (lost tests), gave_up, already_green, running, empty; drift kinds; false claim; replan; worker error.
Keeps: run picker, compare (race), evidence links (draft PR, neatlogs trace, Entire checkpoint).

## Direction contract

THESIS: A run is a strip of film on a lightbox and Kedge is the editor with the red china marker. It refuses the dashboard: no cards, no sidebar table; the replay performs the catch.

OWN-WORLD: Backlit lightbox ground (#f4f6f8 glowing to white), black film rebate (#0b0b0c) with real sprocket holes and orange edge print (#d26a1b, mono), frames as dark positives with white set type, red china-marker (#e3241b) strokes drawn by hand: X over drift, circle on checkpoint and keeper, handwritten notes; yellow grease pencil (#f2b705) only for the agent's false claim. Archivo for set type and the huge verdict word, Permanent Marker for marks, JetBrains Mono for edge print and code.

STORY: Judge watches frames feed through; on the cheat frame the strip halts, a red X is drawn, the strip rewinds with reel inertia to the circled checkpoint, runs on, and the keeper lifts off the sheet as an enlarged print reading 5/5 KEPT. The race mode shows the unguarded strip printing SHIPPED SHORT 2/5. Believes Kedge checks. Clicks a frame for its evidence.

FIRST VIEWPORT: Full-bleed lightbox. Top-left: KEDGE wordmark stamped like a lab label and the sheet stack (run picker). Center: one film strip spanning the width with frames per step, sprockets counting steps. Right/bottom: the enlarged print appears after play. Primary action: Play replay (large, top-right), then Open draft PR on the print. Loupe follows the cursor over the strip.

FORM: Contact Sheet on the Lightbox; assigned candidate 7 of 7 grounded directions by the concept roll, seed key 7e425942, chosen by the user on the decision page. Raises: physical rewind (spring inertia), counts settle with mass, structure is ornament (sprockets = steps), one calm print with one huge word, provenance seam per frame.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
